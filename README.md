# Muneeb Anjum — Portfolio Website

A modern, interactive developer portfolio built with React, TypeScript, and Tailwind CSS. Showcases projects, skills, experience, and education in a terminal-inspired, animated UI.

## ✨ Features
- **Terminal-inspired UI:** Animated, responsive sections styled like terminal windows.
- **Sectioned Navigation:** About, Skills, Experience, Projects, Education, and Contact.
- **Animated Transitions:** Smooth page and section transitions, animated status bars, and interactive cards.
- **Project Portfolio:** Detailed project cards with tech stack, achievements, and GitHub links.
- **Skills Deck:** Categorized skills (languages, frontend, backend, databases, devops, tools) with soft skills.
- **Experience & Education:** Timeline cards with key achievements and details.
- **Contact Section:** Email, location, and social links (LinkedIn, GitHub, Medium) with keyboard shortcuts.
- **Mobile Friendly:** Fully responsive, touch-optimized, and accessible.
- **Downloadable CV:** Quick access to resume/CV.

---

## 🛠️ Tech Stack
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS
- **Animation:** Framer Motion
- **Icons:** React Icons
- **Routing/Scroll:** React Router, React Scroll, Scrollama
- **Deployment:** Vercel

## 🧩 Customization
- **Projects:** Edit `src/components/FeaturedProjects.tsx` to add or update your projects.
- **Skills:** Edit `src/components/Skills.tsx` for your tech stack and soft skills.
- **Experience/Education:** Update `src/components/Experience.tsx` and `src/components/Education.tsx`.
- **Contact Info:** Change email/socials in `src/components/GetInTouch.tsx`.
- **Branding:** Replace images in `public/` and update favicon in `index.html`.
